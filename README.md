# L1 Maths — Synthétique

Site de révision pour la Licence 1 de Mathématiques, présenté sous forme de terminal pixelisé (police VT323, vert phosphore sur fond noir, box-drawing Unicode).

## Contenu

- `index.html` — page d'accueil avec les 5 chapitres (Logique, Algèbre, Analyse, Probabilités, Statistiques)
- `style.css` — thème terminal pixelisé
- `app.js` — navigation et affichage de la progression (localStorage)
- `fiches/logique.html` + `fiches/logique.js` — fiche de cours **Logique** avec 10 exercices interactifs (Propositions, Quantificateurs, Raisonnements)
- `fiches/algebre.html`, `fiches/analyse.html`, `fiches/probabilites.html`, `fiches/statistiques.html` — fiches à venir

## Utilisation

Ouvrir `index.html` dans un navigateur (aucune installation, aucune dépendance hors Google Fonts). La progression de chaque chapitre est sauvegardée localement dans le navigateur (`localStorage`), aucune donnée n'est envoyée à un serveur.
